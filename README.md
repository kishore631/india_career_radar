# 🇮🇳 India Career Radar

**India Career Radar** is a job opportunities website designed to help job seekers discover career opportunities, internships, and entry-level positions across India.

## 🚀 Features

- **Job Listings:** Browse job opportunities from different companies.
- **Search Jobs:** Search by job title, company, skills, or keywords.
- **Location Filters:** Find opportunities based on location.
- **Category Filters:** Explore Software & IT, Data & AI, Customer Support, Finance, and internships.
- **Job Details:** View job descriptions, responsibilities, qualifications, experience, and salary information.
- **Apply Links:** Navigate to the relevant application page.
- **Career Guide:** Explore career development and interview preparation resources.
- **Salary Guide:** Learn about salary and compensation information.
- **Responsive Design:** Access the website on desktop and mobile devices.

## 💻 Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Browse the website in your browser.

## 🌐 Deployment

The website can be deployed using [Vercel](https://vercel.com/) by importing the GitHub repository.

## 🎯 Project Objective

The objective of India Career Radar is to make job searching easier by bringing job listings, application links, and career resources together in one place.

## ⚠️ Disclaimer

Job listings may include sample or illustrative information. Always verify job availability, eligibility, salary, deadlines, and application details on the official employer's website before applying.
